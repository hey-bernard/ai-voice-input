AI 음성 입력 시작하기

어느 앱에서든 단축키를 누르고 말하면, 다듬어진 문장을 커서 위치에 넣어 드립니다. 시작하기 전에 아래 세 가지를 확인하세요.

1. 음성과 텍스트 처리 방식 확인 필요

  • 말한 음성은 받아쓰기를 위해 OpenAI 음성 인식 API로 전송됩니다. 앱은 음성을 디스크에 저장하지 않고, 받아쓰기 세션이 끝나면 메모리에서도 지웁니다.
  • 받아쓴 텍스트는 문장 다듬기를 위해 Anthropic(Claude) API로 전송됩니다. ‘원문 그대로’ 말투를 고르면 전송하지 않습니다.
  • 각 서비스의 데이터 보관 기간은 사용 중인 API 계정의 정책을 따릅니다.
  • 앱은 삽입하지 않은 문장을 비정상 종료에 대비해 저장 폴더에 임시로 저장하고, 삽입하거나 지우면 함께 지웁니다. 삽입한 텍스트는 기본으로 같은 폴더에 기록으로 남기며, ‘데이터·개인정보’에서 기록 보관을 끌 수 있습니다.
  • 보관된 데이터는 언제든 ‘데이터·개인정보’에서 삭제할 수 있습니다.

2. 권한 확인 중

마이크는 음성을 듣는 데, 손쉬운 사용 권한은 다른 앱의 커서 위치에 텍스트를 붙여넣는 데 필요합니다.

3. API 키 확인 중

음성 인식용 OpenAI 키와 문장 다듬기용 Anthropic 키를 입력하세요.

API 키
