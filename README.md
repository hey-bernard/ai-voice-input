# AI 음성 입력 (데스크톱 MVP)

Manyfast 기획서 「AI 음성 입력 앱」을 바탕으로 만든 Windows/macOS 데스크톱 앱입니다.
어느 앱에서든 단축키를 누르고 말하면, 말한 내용을 문장 묶음으로 나눠 받아쓰고, 선택한 말투로 다듬은 뒤, 쓰던 앱의 커서 위치에 넣어 줍니다.

## 빠른 시작 (Windows)

1. [Node.js 20 이상](https://nodejs.org/)을 설치합니다.
2. 이 폴더에서 아래 명령을 차례로 실행합니다.

```bash
npm install
```

```bash
npm start
```

3. 처음 실행하면 설정 창의 **시작하기**가 열립니다.
   - 음성·텍스트 처리 방식에 동의합니다.
   - **API 키**에서 OpenAI 키(음성 인식)와 Anthropic 키(문장 다듬기)를 입력합니다.
4. 메모장 같은 아무 앱에 커서를 두고 `Ctrl + Shift + Space`를 눌러 말합니다. 다시 누르면 받아쓰기가 끝나고, `Ctrl + Enter`를 누르면 커서 위치에 들어갑니다.

설치 파일(.exe)을 만들려면 다음을 실행합니다. 결과물은 `dist/`에 생깁니다.

```bash
npm run dist:win
```

macOS용(.dmg)은 Mac에서 `npm run dist:mac`으로 만듭니다.

## 저장 위치

| 내용 | 위치 |
|---|---|
| 받아쓰기 기록(날짜별 `받아쓰기-YYYY-MM-DD.txt`, `history.json`), 복구용 임시 세션(`recovery.json`) | Windows 기본값 **`D:\AI\aI_record`** (설정 › 데이터·개인정보에서 변경). macOS는 앱 설정 폴더 아래 `records` |
| 설정, 암호화된 API 키 | `%APPDATA%\AI Voice Input` (macOS: `~/Library/Application Support/AI Voice Input`) |

- 지정한 폴더를 만들 수 없으면(예: D 드라이브가 없음) 앱 설정 폴더 아래 `records`에 저장하고, 설정 화면에 그 사실을 표시합니다.
- 음성은 디스크에 저장하지 않습니다.
- 삽입한 텍스트 기록은 기본으로 남습니다. **설정 › 데이터·개인정보 › 기록 보관**에서 끌 수 있습니다.

## 기능과 기획서 대응

| 기획서 요구사항 | 구현 |
|---|---|
| R-MPQSPR 연속 음성 인식·문장 단위 결과 | 침묵(기본 0.9초)을 기준으로 발화를 문장 묶음으로 자르고, 묶음마다 받아쓰기 후 다듬기. 음성이 감지되지 않거나 마이크 권한이 없으면 원인을 안내 |
| R-RGXCOH 어느 앱에서나 시작·삽입 | 전역 단축키(변경 가능, 충돌 감지). 클립보드와 붙여넣기 키로 커서 위치에 삽입한 뒤 원래 클립보드를 복원. 실패하면 클립보드에 복사하고 안내 |
| R-EWWGHC AI 문장 다듬기·말투 | 간결하고 격식 있게 / 친근하고 편안하게 / 원문 그대로 / 맞춤 스타일(추가·수정·삭제). 다듬기에 실패하면 원문을 보존해 삽입 가능 |
| R-ERRLJI 다국어 | 후보 언어 안에서 자동 감지(gpt-transcribe) 또는 고정. 판별 불가·미지원 언어는 표시하고 언어를 지정해 다시 인식 |
| R-UVKFFN 장시간 세션 | 녹음 중 / 처리 중 / 일시정지 / 종료 상태 표시, 경과 시간, 일시정지·재개, 실패한 묶음 재시도, 비정상 종료 시 복구 |
| R-VGZMIY 권한·접근성 | 첫 실행 권한 안내(macOS 마이크·손쉬운 사용), 키보드만으로 모든 조작, 상태를 색이 아닌 텍스트와 스크린 리더 알림으로도 제공 |
| R-PNQGQR 검토·수정 | 묶음별 편집, 원문 보기, 수정 취소, 포함/제외, 개별 삽입 |
| R-BXRNJD 데이터 보호 | 처리 방식 고지와 동의, 저장 폴더 지정, 보관 데이터 삭제와 결과·실패 안내 |

## 받아쓰기 창 단축키

| 키 | 동작 |
|---|---|
| `Ctrl + Shift + Space` (전역) | 받아쓰기 시작/종료 |
| `Ctrl + Shift + Enter` (전역) | 종료하고 바로 삽입 |
| `Ctrl + Enter` | 선택한 묶음 삽입 |
| `Alt + P` / `Alt + S` | 일시정지·재개 / 종료 |
| `Alt + 1~9` | 말투 선택 |
| `Esc` | 창 숨기기 |

macOS에서는 `Ctrl` 대신 `⌘`를 씁니다.

## 구조

```
src/main/main.js      창, 트레이, 전역 단축키, IPC
src/main/ai.js        음성 인식(OpenAI) + 문장 다듬기(Claude, 구조화 출력, 거절 시 서버 측 폴백)
src/main/insert.js    외부 앱 커서 위치에 삽입(Windows: SendKeys, macOS: System Events, Linux: xdotool)
src/main/store.js     설정, 암호화된 API 키, 저장 폴더, 기록, 복구, 삭제
src/renderer/         받아쓰기 창(overlay), 설정 창, 침묵 감지(segmenter), 녹음(recorder)
```

## 테스트

```bash
npm test
```

```bash
xvfb-run -a node test/e2e.electron.js
```

E2E 테스트는 가상 마이크와 가짜 AI 응답으로 앱을 띄워 녹음 → 문장 묶음 → 다듬기(실패 포함) → 수정·제외 → 삽입(실패 시 클립보드 복사) → 저장 폴더 기록 → 데이터 삭제를 확인합니다.

## 알려진 제한

- 관리자 권한으로 실행 중인 Windows 앱에는 붙여넣기 키가 전달되지 않을 수 있습니다. 이때는 클립보드에 복사됩니다.
- 붙여넣기 방식이므로 대상 앱에서 텍스트가 선택되어 있으면 선택 영역이 바뀝니다.
- iOS·Android는 이번 범위에 포함하지 않았습니다(시스템 키보드 확장이 별도로 필요).
